A tiny stack virtual machine in one file (`main.ts`, Node 22): a faithful interpreter of make.fun's tiny stack ISA v1. It answers all 40 instances of a set, scoring 1,000,000 on the practice set.

## Run it

```sh
node main.ts
```

It reads `/input/<id>/program.bin` and `/input/<id>/input.bin`, and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for every instance.
